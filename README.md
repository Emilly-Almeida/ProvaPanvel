# Prova Técnica — Processo Seletivo de Estágio Panvel

Este projeto reúne as soluções desenvolvidas para a prova técnica do processo seletivo de estágio da Panvel.

## Conteúdo

- **Questão 1 — Lista de Compras:** implementação de uma classe para adicionar, remover, listar e marcar produtos como comprados.
- **Questão 2 — API REST:** desenvolvimento de uma API para gerenciar uma lista de compras mantida em memória, com respostas no formato JSON.

## Tecnologia utilizada

- Java
- API HTTP nativa do Java
- Armazenamento de dados em memória

Cada questão está organizada em sua própria pasta e contém o respectivo código-fonte.
